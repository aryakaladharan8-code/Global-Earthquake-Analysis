# 🌍 Global Earthquake Analysis (2020–2026)

## 📌 Project Overview

Earthquakes are natural disasters that can cause significant damage to infrastructure, the environment, and human lives. Understanding their patterns, magnitude, depth, and geographical distribution is important for studying seismic activity across the world.

This project focuses on analyzing global earthquake records from 2020 to 2026 using Exploratory Data Analysis (EDA) and interactive data visualization.

The analysis explores earthquake magnitude, depth, geographical distribution, temporal trends, and relationships between different seismic attributes. A Tableau dashboard is also developed to present the findings through interactive visualizations.

## 🎯 Project Objectives

* Analyze the global distribution of earthquake occurrences.
* Understand earthquake magnitude and depth distributions.
* Identify regions with frequent earthquake activity.
* Examine yearly and monthly earthquake trends.
* Investigate relationships between earthquake magnitude and depth.
* Identify outliers and unusual earthquake events.
* Explore meaningful patterns and insights through data visualization.

The Global Earthquake Analysis project uses exploratory data analysis and interactive visualization to investigate earthquake activity worldwide between 2020 and 2026.

The combination of Python and Tableau helps transform raw earthquake records into understandable visual insights.
